# 🌧️ Monsoon Mayhem (মনসুন মেহেম: বর্ষার রাস্তায় স্কুটার সারভাইভাল)

> **"Kolkata's Roads. Your Worst Nightmare."**  
> *"বাড়ি ফিরতে বেরিয়েছিলাম, সাবমেরিন হয়ে গেলাম!"*

A chaotic, funny, pseudo-3D endless survival driving game built with **Phaser 3**, **TypeScript**, and **Vite**.

---

## 🎮 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Build for production
npm run build
```

---

## 🕹️ Controls

| Action | Desktop Key | Mobile Touch |
| :--- | :---: | :---: |
| **Steer Left** | `A` or `Left Arrow` | On-screen Left Button |
| **Steer Right** | `D` or `Right Arrow` | On-screen Right Button |
| **Accelerate** | `W` or `Up Arrow` | On-screen Gas Button |
| **Brake / Reverse** | `S` or `Down Arrow` | On-screen Brake Button |
| **Jump** | `Spacebar` | On-screen Jump Button |
| **Pause** | `Esc` or `P` | Menu Button |
